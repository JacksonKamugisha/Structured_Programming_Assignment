# __STRUCTURED PROGRAMMING ASSIGNMENT__
An assignment whose aim is to test competency in C programming and ability to post work onto Github

## Question 1: *Basic printf Statement*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 2, Exercise 2.4 b).
- A basic printf statement that gets displayed to the user.

## Question 2: *Compares Rainfall*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 2, Exercise 2.18.
- A basic program that compares two values read from the user, in this example we compare the highest rainfall recorded in Vietnam and the current rainfall recorded in Vietnam. If the current rainfall is greater than the highest ever recorded, the program updates the previous highest rainfall to the current one.

## Question 3: *Mortgage Calculator*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 3, Exercise 3.17.
- A mortgage calculator that reads mortgage, mortgage term in years and Interest rate from the user.

## Question 4: *Sum and Average of Integers Calculator*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.9.
- A program that reads the first value from the user and uses it to get the average of other values that are in a for loop that loops for as many times as the first value that was given by the user.

## Question 5: *Sum of Multiples of 7*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.11.
- A program that uses a do while loop to print the multiples of 7 from 1 to 100.

## Question 6: *Sales Calculator*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.19.
- A program that uses a switch statement to display total retail value of all products sold the week prior after reading the product number and quantity from the user.

## Question 7: *Compound Interest Calculator with Integers*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 4, Exercise 4.23.
- This program displays a table of compound interest with integers with one side as years and the other is amount on deposit.

## Question 8: *Rectangle of Asterisks*
- Source: Deitel & Deitel, C How to Program, 9th Edition, Chapter 5, Exercise 5.19.
- A for loop that prints a rectangle of asterisks (*) based  on the parameters set by side1 and side2.
